# 小布识屏增强

适用于 ColorOS 的 LSPosed 模块，扩展小布识屏和屏幕翻译的可用页面，提供识图、保存截图和快速启动，并支持可选的全屏单指长按。

## v2.2.4 识图菜单与抖音返回

移除不可用的 Bing 入口及搜索路由。识图菜单保留 Google、Yandex、抖音、百度、搜狗、WhatAnime；引擎 ID 保持不变，删除一项不会使 WhatAnime 点击后误跳其他服务。

抖音搜图改为先进入正常应用任务，再将结果页放在其上。搜图页按返回后回到抖音，可继续浏览；此后从桌面重新打开抖音，不再恢复已经退出的搜图页。冷启动和已运行两种情况均已在抖音 40.8.0 验证。保留 v2.2.2 的重新框选，以及直连、统一图标和隐藏桌面入口等功能。

## v2.2.2 抖音重新框选

补齐原版“拍照问”从相册进入时的 `showBg=1`、`showSelector=1` 和 `pageRatio=0.6` 参数，恢复原图上的选区及正常结果面板高度。每次搜索保留独立缓存，前一页的原图不再被后一次搜索覆盖。

实机已验证选区出现、拖动后选区和缩略图更新并触发重新搜索；随后抖音要求本人完成账号安全验证，新结果加载尚未验证。APK 构建及签名校验通过，已覆盖安装 v2.2.2。本次仅修复此交互，未重复运行上版全部回归测试。

## v2.2.1 识图修复

抖音入口改为通过模块的短时 root 桥接，复制当前识屏图片到抖音自己的缓存，并传递原生 `question` 模式图片参数，打开“拍照问”结果页。已在抖音 40.8.0 实测带图进入并生成 AI 回答；其他版本明确提示不支持，避免内部参数变化后误跳转。需要允许模块使用 root。

Bing 图片链接入口补齐 `sbisrc=UrlPaste` 与 `idpbck=1` 等参数，合成图已识别为红色正方形。当前国内 Bing 可能把图片识别转成文字搜索结果，由服务端决定。仍使用搜狗优先上传及原有图床后备顺序。

模块上传通过物理网络和 `Proxy.NO_PROXY` 发请求，小布识屏进程绑定物理网络。实测 Clash VPN 保持连接时，上传及小布进程使用 Wi-Fi 网络 100；不修改 VPN、系统代理和其他设备设置。网页打开后的联网仍由所选浏览器管理。

七个引擎采用同一套 24dp 彩色圆角图标，不再使用通用 Android 占位图标。9 组 JVM 回归测试及 APK 构建、签名校验通过，v2.2.1 已覆盖安装到测试手机。本次未重新验证视频亮度；保留此前亮度修复。

## v2.2.0 开发版：隐藏入口与网页识图

设置中可隐藏模块自身的桌面入口。隐藏后桌面、应用抽屉和抽屉搜索均不显示，可从 LSPosed 的模块设置重新进入并关闭隐藏。首次安装默认隐藏，旧版升级保留已有的显隐状态。

识图菜单增加百度、搜狗、Bing、WhatAnime 网页入口；Google、Yandex 保留应用和网页选项。所有网页识图优先使用搜狗网页上传，取得 HTTPS 图片链接后交给所选引擎；上传失败才回退到原有图床。搜索图片会上传到所用服务，网页结果由默认浏览器打开。

合成图片实测：搜狗上传到结果链接约 0.24–0.33 秒（不含页面加载）；百度读取图片并给出结果，WhatAnime 读取图片后完成搜索。Bing 原 searchbyimage 地址在当前环境失效，改为 images/search 的图片链接入口，可识别测试图并跳转结果页。以上是小图片的单次测试，不代表整屏截图或所有网络下的耗时。抖音入口仍在修复，当前版本不能保证自动带图进入抖音识图。

## v2.1.9 适配小布识屏 17.7.8
修复小布识屏17.7.8无法使用的问题

## v2.1.8 视频亮度兼容修复

底部触碰窗口改用导航面板类型，避免系统错误窗口阻止下层播放器的窗口亮度覆盖，导致亮度提示变化但画面不变。保留底部短按触发和滑动取消逻辑，以及 v2.1.7 的小图与头像提取改进。**覆盖安装后必须重启手机**。

## v2.1.7 小图与头像识别（测试版）

移除原生 58 dp 面积边长和 40 dp 最短边的小图门槛，允许头像和小图参与提取。针对 GIF 原图与裁剪缩略图尺寸不符、原生提取失败等情况，在原生结果排序前，用同一次截图中的可见图片边界补齐遗漏图片，复用原生裁图、保存和菜单流程。已有相同边界的图片不重复补入，完全不可见或越界的区域不会恢复。

实机在酷安复现九宫格 GIF 多图被 `unmatched bitmap size` 丢弃；测试版安装后，QQ 列表头像、哔哩哔哩缩略图已出现识别框，用户反馈可用。原九宫格的逐张复测尚未完成。后备提取依赖应用暴露的图片布局信息；自绘 Canvas 等未暴露独立边界的图片仍可能无法自动分离。GIF 后备结果为截图中的静态可见帧，不保证提取动态原文件。未对新版识别速度做基准测试。

## v2.1.6 修复上滑误触发

修复从底部区域上滑也启动识屏的问题：恢复短按抬手判定，滑动超过系统触摸容差、多指、取消或按住超过 250 毫秒均不启动。保留底部 144 × 18 dp 独立区域，隐藏小白条时仍可轻点触发。**覆盖安装后必须重启手机**。设置入口为“底部触碰识屏”，不依赖小白条显示或手势导航模式。实机验证两次上滑、一次 800 毫秒长按均未触发，单次短按只启动一次。v2.1.5 因上滑误触发已撤下，请使用 v2.1.6。

## v2.1.4 动画调整

恢复原生启动扫描动画，包括渲染器、扫描资源和窗口显示，并将启动和循环扫描动画设为原生播放速度的两倍。识别完成时立即停止动画，取消 1200 毫秒最低播放等待及结束后的 50 毫秒延时；云端预等待和规则缓存优化继续保留。

## v2.1.3 性能优化

v2.1.3 进一步取消桌面识屏前的 150 毫秒云端等待，跳过已关闭扫描效果的资源加载，并对服务器明确返回“无匹配”的动态图片规则缓存 60 秒。详细耗时日志默认关闭。

在同一复杂双栏图文页上，从导航触发到原生识别就绪的中位耗时，进程冷启动由 **1785 → 1551 毫秒**，连续识别由 **1375 → 1240 毫秒**。首次未命中规则缓存仍有波动，不保证每次冷启动更快。测量口径、全部样本和限制见 [性能测试记录](PERFORMANCE.md)。

## 功能

1.解除限制模块，可以在所有界面调取小布识屏

2.为小布识屏添加保存截图功能

3.为小布识屏添加识图功能，自动调取手机的yandex和Google识图，也可进行网页版搜图

4.翻译功能放可在所有界面翻译生效

5.保留启动扫描动画，识别完成立即结束，优先继续本地 OCR 识别

6.增加单指长按功能（需要打开无障碍）

7.保留原生显示，支持按词点击、滑动多选、取消、复制和搜索，复制不添加换行

8.支持单击小白条唤起识屏并短震反馈，恢复提取文字，统一浅色和深色图标


需要系统本身提供小布识屏和屏幕翻译。当前适配基于一加 15、ColorOS 17、小布识屏 17.5.14；不同系统或应用版本仍可能需要适配。接口不匹配时停用对应增强，保留原生流程，无法保证所有设备、所有页面均可使用。
