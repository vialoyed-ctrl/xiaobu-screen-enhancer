# 小布识屏增强

给 ColorOS 的小布识屏加点功能。需要 Root 和 LSPosed，手机本身也要有小布识屏和屏幕翻译。

[下载最新版](https://github.com/vialoyed-ctrl/xiaobu-screen-enhancer/releases/latest)

## 功能

- 在桌面和更多应用里唤起小布识屏、屏幕翻译。
- 点小白条识屏，也可以开启全屏单指长按。
- 保存截图，提取页面里的图片、头像和小图。
- 调用 Google、Yandex 等应用搜图，也支持百度、搜狗、抖音和 WhatAnime 等网页版搜图。
- 按词选中文字，点击或滑动多选，支持复制、搜索，复制时不额外加换行。
- 加快识屏和扫描动画，识别完成就结束动画。
- 隐藏模块的桌面图标。

## 使用

1. 从 Releases 下载 APK，安装后在 LSPosed 中启用模块。
2. 勾选模块推荐的作用域，重启手机。
3. 打开模块设置，按需开启底部触碰识屏、单指长按等功能。单指长按还需要开启模块的无障碍服务。

更新时直接覆盖安装，原设置会保留，装完重启一下。隐藏桌面图标需要给模块 Root 权限。

## 适配情况

目前主要在一加 15、ColorOS 17 上测试，小布识屏测试版本包括 17.5.14、17.7.8 和 17.7.10。其他机型、系统版本可能需要单独适配，也不是每个页面都能正常识别。

目前仓库源码还没同步到 2.2.7，使用最新版请下载 Releases 里的 APK。
