# 小布识屏增强

一个用于 ColorOS 小布识屏的 LSPosed 模块，让原有方式在更多应用页面启动识屏。

新增“保存截图”按钮，位于识屏底部操作栏。它将识屏抓取的原画面保存到相册的 `Pictures/小布识屏增强`，成功后自动退出识屏。

[下载 v1.4 APK](release/小布识屏增强-v1.4.apk) · [查看源码](src/main)

在 LSPosed 中启用模块，作用域只勾选 `com.coloros.colordirectservice`。

## 兼容性

在 OnePlus PLK110、ColorOS 17、小布识屏 17.4.14 上测试。桌面页面已验证按钮可保存截图并自动退出。其他系统版本尚未逐一验证。
