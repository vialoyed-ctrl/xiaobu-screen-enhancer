# 小布识屏增强

适用于 ColorOS 的 LSPosed 模块，扩展小布识屏和翻译的可用页面，增加识图、截图、按词选择和快捷启动功能。

[下载 v2.1.0 APK](https://github.com/vialoyed-ctrl/xiaobu-screen-enhancer/releases/download/v2.1.0/XiaobuScreenEnhancer-v2.1.0.apk) · [查看源码](src/main)

## 功能

- 在更多应用页面调用小布识屏和屏幕翻译，优化识屏启动过程。
- 保留原生显示，支持点击整词、滑动选词、多选、取消、复制与搜索；复制时去掉换行。
- 保留原生“提取文字”功能，新增小图片搜图入口。
- 支持 Google、Yandex 应用或网页识图，截图保存到相册。
- 支持单击小白条启动识屏并短震反馈，以及可选的全屏单指长按。
- 新增图标统一描边风格，跟随浅色、深色模式。

## 使用

安装 APK，在 LSPosed 中启用模块并勾选推荐作用域：**小布识屏、翻译、系统框架**，然后重启手机。更新系统框架中的代码后也需要重启。

小白条触发默认开启，无需长按检测辅助功能。只响应导航条中央的短按，滑动、多指和长按均不触发；反馈为一次 40 毫秒短震。识屏冷启动时，模块为目标应用申请三秒临时启动放行，不添加永久白名单。

如需全屏单指长按，在模块设置中开启，并在辅助功能中开启“小布识屏增强 · 长按检测”。实际弹出操作菜单或开始拖动时，优先保留原生操作。

## 网页识图

网页模式会把图片副本上传至公开图床，再使用图片直链打开 Google 或 Yandex，结果交给系统默认浏览器。

- 按 postimg.cc、IM.GE、pixhost.top 的顺序处理；上传失败自动尝试下一站。
- **Postimages 已明确禁止网页自动上传，要求官方 API 授权。当前没有配置授权，模块会直接跳过该站。**
- IM.GE 使用不过期、NSFW、未列出设置；pixhost.top 使用不过期设置，该站没有 NSFW 选项，且存在匿名上传额度。
- 不过期表示不主动设置删除时间，无法保证第三方服务永久保留图片。知道直链的人可以访问图片，请留意截图内容。
- 图片默认不再使用原来一小时过期的临时图床。所有候选站点失败后提供重试，不回退到旧图床。

## 兼容性

需要系统本身提供小布识屏和屏幕翻译。适配基于一加 15、ColorOS 17、小布识屏 17.5.14。不同系统版本仍可能需要适配，无法保证所有设备、所有页面均可使用。

源码位于 `src/main`，构建与测试方法见 [BUILDING.md](BUILDING.md)。
