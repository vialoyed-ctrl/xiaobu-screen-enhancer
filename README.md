# 小布识屏增强

一个用于 ColorOS 小布识屏的 LSPosed 模块。它放宽桌面入口、应用黑名单和安全窗口预检查，让原有方式在更多应用页面启动识屏。

## 功能

- 桌面也能启动小布识屏。
- 通用跳过小布识屏的应用黑名单，无需逐个配置应用。
- 通用跳过小布识屏自身的安全窗口预检查。

## 安装

1. 安装 [小布识屏增强 v1.3 APK](release/小布识屏增强-v1.3.apk)。
2. 在 LSPosed 中启用模块，作用域只勾选 `com.coloros.colordirectservice`。
3. 强制停止小布识屏进程，随后用现有手势或磁贴启动识屏。

关闭模块并强制停止小布识屏即可撤销作用。模块不会修改 Xposed Edge、系统分区或小布识屏 APK。

## 兼容性

在 OnePlus PLK110、ColorOS 17、小布识屏 17.4.14 上测试；桌面、Telegram Plus、相机和冰箱页面可进入识屏，相机和冰箱已完成 OCR。其他系统版本和页面尚未逐一验证。Android 系统级截图保护仍可能导致画面为空白。

源码位于 [`src/main`](src/main)。模块基于传统 Xposed API 82。
