# 小布识屏增强

适用于 ColorOS 的 LSPosed 模块，让小布识屏和屏幕翻译可以在更多页面使用，并加入“识图”和“保存截图”功能，支持调用 Google 或 Yandex 识图。

## 安装

下载并安装 [v1.8 APK](release/XiaobuScreenEnhancer-v1.8.apk)，在 LSPosed 中启用模块，使用推荐作用域：小布识屏、翻译、系统框架，然后重启手机。

## 兼容性

适配一加 15、ColorOS 17、小布识屏 17.4.14、系统翻译 17.1.30，其他设备和系统版本可能需要适配。

v1.8 新增翻译浮窗层级调整，通知栏场景尚待重启后实机验证。
