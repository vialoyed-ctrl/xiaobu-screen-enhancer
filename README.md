# 小布识屏增强

适用于 ColorOS 的 LSPosed 模块，扩展小布识屏和屏幕翻译的可用页面，提供识图、保存截图和快速启动，并支持可选的全屏单指长按。

## v2.1.8 视频亮度兼容修复

底部触碰窗口改用导航面板类型，避免系统错误窗口阻止下层播放器的窗口亮度覆盖，导致亮度提示变化但画面不变。保留底部短按触发和滑动取消逻辑，以及 v2.1.7 的小图与头像提取改进。**覆盖安装后必须重启手机**。

## v2.1.7 小图与头像识别（测试版）

移除原生 58 dp 面积边长和 40 dp 最短边的小图门槛，允许头像和小图参与提取。针对 GIF 原图与裁剪缩略图尺寸不符、原生提取失败等情况，在原生结果排序前，用同一次截图中的可见图片边界补齐遗漏图片，复用原生裁图、保存和菜单流程。已有相同边界的图片不重复补入，完全不可见或越界的区域不会恢复。

实机在酷安复现九宫格 GIF 多图被 `unmatched bitmap size` 丢弃；测试版安装后，QQ 列表头像、哔哩哔哩缩略图已出现识别框，用户反馈可用。原九宫格的逐张复测尚未完成。后备提取依赖应用暴露的图片布局信息；自绘 Canvas 等未暴露独立边界的图片仍可能无法自动分离。GIF 后备结果为截图中的静态可见帧，不保证提取动态原文件。未对新版识别速度做基准测试。

## v2.1.6 修复上滑误触发

修复从底部区域上滑也启动识屏的问题：恢复短按抬手判定，滑动超过系统触摸容差、多指、取消或按住超过 250 毫秒均不启动。保留底部 144 × 18 dp 独立区域，隐藏小白条时仍可轻点触发。**覆盖安装后必须重启手机**。设置入口为“底部触碰识屏”，不依赖小白条显示或手势导航模式。实机验证两次上滑、一次 800 毫秒长按均未触发，单次短按只启动一次。v2.1.5 因上滑误触发已撤下，请使用 v2.1.6。

## v2.1.4 动画调整

恢复原生启动扫描动画，包括渲染器、扫描资源和窗口显示，并将启动和循环扫描动画设为原生播放速度的两倍。识别完成时立即停止动画，取消 1200 毫秒最低播放等待及结束后的 50 毫秒延时；云端预等待和规则缓存优化继续保留。

## v2.1.3 性能优化

v2.1.3 进一步取消桌面识屏前的 150 毫秒云端等待，跳过已关闭扫描效果的资源加载，并对服务器明确返回“无匹配”的动态图片规则缓存 60 秒。详细耗时日志默认关闭。

在同一复杂双栏图文页上，从导航触发到原生识别就绪的中位耗时，进程冷启动由 **1785 → 1551 毫秒**，连续识别由 **1375 → 1240 毫秒**。首次未命中规则缓存仍有波动，不保证每次冷启动更快。测量口径、全部样本和限制见 [性能测试记录](PERFORMANCE.md)。

## 功能

1.解除限制模块，可以在所有界面调取小布识屏

2.为小布识屏添加保存截图功能

3.为小布识屏添加识图功能，自动调取手机的yandex和Google识图，也可进行网页版搜图

4.翻译功能放可在所有界面翻译生效

5.保留启动扫描动画，识别完成立即结束，优先继续本地 OCR 识别

6.增加单指长按功能（需要打开无障碍）

7.保留原生显示，支持按词点击、滑动多选、取消、复制和搜索，复制不添加换行

8.支持单击小白条唤起识屏并短震反馈，恢复提取文字，统一浅色和深色图标


需要系统本身提供小布识屏和屏幕翻译。当前适配基于一加 15、ColorOS 17、小布识屏 17.5.14；不同系统或应用版本仍可能需要适配。接口不匹配时停用对应增强，保留原生流程，无法保证所有设备、所有页面均可使用。
