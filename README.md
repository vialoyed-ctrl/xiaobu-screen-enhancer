# 小布识屏增强

适用于 ColorOS 的 LSPosed 模块，扩展小布识屏和屏幕翻译的可用页面，提供识图、保存截图和快速启动，并支持可选的全屏单指长按。

## 功能

- 在更多应用页面启动小布识屏和屏幕翻译。
- 底部增加“识图”和“保存截图”，沿用小布识屏的按钮及菜单风格。
- 识图支持将当前截图交给已安装的 Google 或 Yandex；选定后自动保存，取消不保存。
- 保存截图时按原生返回动画退出，后台写入相册的 `Pictures/小布识屏增强`，不显示成功 Toast。
- 跳过启动扫描特效及固定展示等待；联网时让原生本地 OCR 尽早开始，保留云端请求和原生结果处理。
- 单指长按默认关闭，可设置时长并排除应用；滑动、多指、抬手、锁屏或窗口变化会取消；实际操作菜单、选字工具栏和拖动优先，普通文字不会直接拦截识屏。

## 使用

安装 `XiaobuScreenEnhancer-v2.0.3.apk`，在 LSPosed 中启用模块并勾选推荐作用域：**小布识屏、翻译、系统框架**，然后重启手机。更新系统框架中的代码后也需要重启。

如需单指长按，打开模块设置，开启开关，并在系统辅助功能中开启 **“小布识屏增强 · 长按检测”**。默认跟随系统双指长按时长，再等待约 100 毫秒避让原生操作；同一次按住只触发一次，并轻震提示。

长按检测服务只接收操作弹窗等窗口事件的类型、应用包名和时间，不读取页面文字或节点，也不申请模拟手势能力。部分游戏或自绘控件不报告原生长按事件，无法可靠区分时可将应用加入排除列表。

## 兼容性

需要系统本身提供小布识屏和屏幕翻译。当前适配基于一加 15、ColorOS 17、小布识屏 17.5.14；不同系统或应用版本仍可能需要适配。接口不匹配时停用对应增强，保留原生流程。无法保证所有设备、所有页面均可使用。

v2.0 将截图捕获、会话生命周期、后台保存及界面按钮拆分，增加旧截图失效、资源租用、重复操作保护和有界任务队列；启动动画加速限定在实际入场流程。

源码位于 `src/main`，构建与测试方法见 [BUILDING.md](BUILDING.md)。
